# Hydrogen-Line Persistent Memory + HH Awareness Cloud Service

This document defines the persistent memory system now used by hydrogen-line agent tests, and the cloud service surface that manages it.

## 1) Persistent memory system (defined)

**System name:** `HLMEM v1` (Hydrogen-Line Memory v1)  
**Role:** persistent memory layer for writer/reader/verifier agent workflows  
**Namespace:** hydrogen-line (`1420.405751768 MHz` canonical constant)

### Data model

Each write stores a record:

- `id` - unique memory record id
- `namespace` - usually `hydrogen-line`
- `location_hash` - resolved hydrogen-line location
- `run_id` - orchestration run identifier
- `writer_agent` - agent label for provenance
- `key` - random key generated by writer
- `value` - payload object written by writer
- `value_hash` - SHA-256 hash of serialized value
- `created_at_utc` - write timestamp

### Persistence adapters (priority)

1. **GitHub Contents API (cloud-persistent)**  
   Activated when:
   - `HLINE_GITHUB_TOKEN`
   - `HLINE_GITHUB_REPO`
   are set.

   Optional:
   - `HLINE_GITHUB_BRANCH` (default `main`)
   - `HLINE_GITHUB_FILE_PATH` (default `data/hline-memory-store.json`)

2. **Local file persistence**  
   Default fallback:
   - `data/hline-memory-store.json`
   - configurable with `HLINE_MEMORY_FILE`

3. **In-memory fallback**  
   Not used as primary in this build path.

## 2) Cloud service (implemented)

### A) Roundtrip execution endpoint

- `GET /api/hydrogen-line-agent-roundtrip`
- Runs 3 independent agents:
  - Writer -> generates random key and writes memory
  - Reader -> resolves same location and reads memory
  - Verifier -> validates location/key/run/hydrogen-line checks
- Sources OpenWebRX public context (`/status.json`) for hydrogen-line context
- Reports persistence mode and success/failure in output JSON

### B) HH Awareness AI OS cloud management endpoint

- `GET /api/hh-awareness-cloud`
  - Returns cloud service definition, persistence mode, and available actions

- `POST /api/hh-awareness-cloud`
  - `action: run_hydrogen_line_roundtrip`
  - `action: write_hydrogen_line_memory`
  - `action: read_hydrogen_line_memory`

## 3) Operational notes

- This is a software cloud memory/networking demonstration in hydrogen-line namespace.
- Public/free API source currently used for line context: OpenWebRX public `status.json`.
- When GitHub adapter env vars are provided, memory becomes cloud-persistent across runs.
